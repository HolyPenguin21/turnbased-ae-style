# Terrain complex palette normalization

Generated by Tools/terrain-assets/normalize_clusters.py.

Each biome is evaluated independently against all ordinary terrain textures configured in GameConfig (main + alternatives). The fitted target still weights Desert, Sand dunes and Rock desert more strongly because authored complexes can actually be placed only on those surfaces.

One shared OKLab transform is fitted per complex family and biome. Animated frames are never normalized independently, preventing color/brightness flicker. RGB is adjusted; dimensions and alpha are preserved.
