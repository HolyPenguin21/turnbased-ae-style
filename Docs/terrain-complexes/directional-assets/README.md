# Отдельно освещённые ракурсы комплексов

Набор из 30 PNG подключён к пустынному биому через `GameConfig.asset`. Каждое семейство имеет шесть готовых шаблонов: 0°, 60°, 120°, 180°, 240°, 300°. Текстуры находятся в `Assets/Textures/Terrain/Desert/Complexes/Directional/`.

Используется существующий `HexMapGenerator.PlaceComplexes()` и `TerrainComplexPlacement.ChooseFromExclusiveGroups()`. Все 12 шаблонов остаются в единой группе `centerpiece`, с весом `count=1`. На карту выбирается один шаблон группы: вероятность каньона — 6/12, машины — 6/12; условная вероятность каждого ракурса — 1/6. После выбора прежнее распределение количества комплексов использует вес выбранного шаблона 1, как и раньше. Дополнительных независимых комплексов на карте не появляется.

Для всех шаблонов `randomizeRotation=0`: смещения и свет уже нарисованы. Геометрия и UV больше не вращают запечённые тени. При изменении весов семейства следует менять `count` всех шести его шаблонов одинаково, иначе изменятся вероятности отдельных ракурсов.

Степной биом (`AridSteppe`) сохраняет свои исходные изображения и палитру. Его механическое вращение отключено, пока для него не подготовлены отдельно освещённые ракурсы. Анимированные одиночные комплексы, правила размещения, проходимость и общий бюджет комплексов не изменены.

Оригинальные ассеты не перезаписаны, их GUID сохранены. Пять частей 0° скопированы из предоставленного пользователем набора в новую папку; 25 остальных частей — новые изображения. Палитра новых ракурсов уточнена встроенным ImageGen по предоставленным оригиналам. Каждый ракурс нарезан из одного непрерывного изображения; дальнейшая цветокоррекция при нарезке не применялась. Смещения, GUID и SHA-256 указаны в `offsets.json`.

`color-check.json`: медианный цвет тёплого грунта новых вариантов отличается от предоставленных оригиналов на ΔE76 1,35–3,87. Это оценка палитры, не доказательство точного совпадения всех участков и контраста. `export-check.json`: проверены 30 PNG, исходные пять частей и 15 общих границ новых ракурсов. Это проверка изображения вне Unity.

## Проверки

```sh
python3 Tools/terrain-assets/verify_directional_assets.py
node Tools/unity-yaml-verify/verify_full.js Assets/Config/GameConfig.asset
node Tools/unity-yaml-verify/verify_types.js Assets/Config/GameConfig.asset
```

Проверка Python сверяет реальные ссылки конфигурации, смещения частей, хеши PNG, уникальные GUID, sRGB и Clamp, отключение вращения и равенство весов семейств.

В среде доставки нет .NET и Unity. Повторный запуск C#-стенда невозможен (`dotnet: command not found`); ранее выполненные 38 проверок относятся к предыдущей реализации вращения, а не к этой интеграции. Код генератора и C#-тесты здесь не менялись.

Перед визуальным принятием открыть проект в Unity 6000.5.4f1, запустить EditMode-тесты и многократно генерировать пустынную карту. Проверить все 12 шаблонов, направление теней, масштаб, стыки между частями и с обычным грунтом при игровой камере. Для степи проверить исходный ракурс и отсутствие механического вращения. Автоматические проверки PNG и YAML не заменяют эти проверки движка.
