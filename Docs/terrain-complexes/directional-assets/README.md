# Отдельно освещённые ракурсы комплексов — v6

Пустынный биом использует 18 частей каньона и 12 частей машины: по шесть ракурсов с шагом 60°. Ссылки `GameConfig.asset`, GUID, настройки импорта, смещения частей и веса семейств сохранены. Все шаблоны имеют `randomizeRotation=0`; UV и готовое освещение не вращаются в игре.

В v6 перерисованы все шесть каньонов: русло шире, в глубине видны стенки и дно, кромки мягче переходят в песок. Каждый цельный исходник согласован с тремя хексами одним пространственным преобразованием до нарезки. Русло проходит через центр каждой клетки; каменные плечи имеют запас до внешней границы комплекса. Части по отдельности не сдвигались. Наклон камеры — 75°, ортографическая проекция, yaw 0°; свет сверху слева.

Цвет и яркость песка согласованы с исходными предоставленными частями. Максимальное отклонение среднего RGB — 0,414 из 255. Проверены 18 новых частей и 12 внутренних стыков каньонов; максимальная средняя погрешность RGB стыка — 1,042 из 255. `registration-and-palette-v6.json` содержит преобразования и статистику палитры, `visual-consistency.json` — актуальные измерения всех 30 частей. Манифест `offsets.json` содержит актуальные SHA256.

Машины и степной биом не менялись. Вероятности, проходимость, количество комплексов и правила размещения сохраняются. Для единой группы `centerpiece` у всех 12 шаблонов вес 1; вероятность каньона и машины 6/12, каждого ракурса выбранного семейства 1/6.

## Проверки

```sh
python3 Tools/terrain-assets/verify_directional_assets.py
python3 Tools/terrain-assets/audit_visual_consistency.py
python3 Tools/terrain-assets/verify_canyon_camera.py
```

Превью `Canyon_v6_Preview.png` собрано из итоговых частей без затухания внутренних границ и не является скриншотом Unity. Код отображения не изменён: текущий `HexTileMeshGenerator` делает прозрачными также общие края частей комплекса. Поэтому полосы фона поперёк каньона требуют отдельного исправления движка; замена PNG их не устраняет.

Unity не запускалась. В редакторе необходимо проверить все шесть ракурсов под игровой камерой. Проверки хешей, палитры и стыков не доказывают правильность перспективы и света в игровом запуске. Файлы `color-check.json`, `export-check.json` и `palette-normalization.json` относятся к предыдущему экспорту v5 и не являются актуальными доказательствами v6.

При интеграции сохранены побайтово все 30 актуальных `.meta` из `master`, включая настройку `textureType: 8`. Старый `verify_directional_assets.py` требует `textureType: 0`, поэтому эта предпосылка уже не соответствует текущим настройкам импорта. Для интеграции отдельно проверены SHA256 PNG, GUID, ссылки конфигурации, sRGB/Clamp и совпадение всех `.meta` с исходной ревизией. Сам проверочный скрипт и настройки импорта не менялись.
