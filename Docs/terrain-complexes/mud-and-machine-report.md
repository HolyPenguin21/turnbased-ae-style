# Грязевое поле и завал машины — Arid и Desert

В GameConfig добавлены Boiling mud field и Giant machine wreck. Arid использует
mapGeneration.terrainTypes/complexes, Desert — desertOverride. Каждый биом получает
один двуххексовый грязевой комплекс с семью синхронными кадрами при 3 FPS и один
статичный трёххексовый завал по прямой. Отдельные исходники/34 текстуры подготовлены
встроенным imagegen с палитрами своих биомов; точные промпты сохранены в Tools/terrain-assets.

Все шесть поворотов разрешены. Базовые типы: Desert, Sand dunes, Rock desert.
baselineWeight=0, blocksGroundMovement=true, добыча нулевая; Mountains не изменён.
Текстуры и последовательности кадров заменяются через существующие записи GameConfig.
При старте существующий HexMapGenerator.PlaceComplexes обрабатывает эти записи;
TerrainComplexPlacement.TryValidate сохраняет связность и размещает весь комплекс
либо пропускает его с диагностикой. HexMap.CanEnter остаётся владельцем проходимости,
HexPathfinder/SafeStepPathing — маршрутов, MapTerrainAnimator — синхронных кадров.
Изменений этих runtime методов для новых типов не потребовалось.

Визуал: по отдельной 512×512 текстуре на хекс, согласованная непрерывная выборка
исходника, существующий мягкий тёмный альфа-стык на внешних и внутренних границах.
Диагностические PNG и GIF рядом показывают оба биома без эмуляции камеры/URP.

Выполнено: validate.py проверил обе палитры, все GUID/изображения, размеры, кадры,
количества, разрешённые основания, нулевую добычу, веса и Mountains; 24 managed
теста прошли, включая наземный обход/воздушный пролёт, атомарное отклонение,
связность, шесть поворотов новой цепочки и синхронность кадров.
AuthoredComplexesKeepBothBiomesConnectedAtEverySize расширен до четырёх шаблонов,
160 сочетаний биом/размер/seed; этот тест требует настоящего Unity.

Не выполнено без Unity: настоящий EditMode/PlayMode, генерация Small–Huge
в движке, подтверждение свободных от комплексов мест для баз/армий/событий/ресурсов
в живой партии, скриншоты в игровом масштабе и оценка семи фаз в игровом рендере.
Ветка PR не слита в master; функционал будет доступен после принятия PR.
