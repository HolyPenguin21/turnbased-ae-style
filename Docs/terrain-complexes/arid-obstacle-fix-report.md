# Оценка препятствий ИИ и комплексы Arid

Исходная ревизия: `b77c0f37cc110719561ea2b9848cfdc0660502b7`, актуальный `master` на начало работы. Рабочее дерево было чистым. Ветка: `fix/terrain-obstacles-arid`.

## Подтверждённые причины и исправления

1. `ReconGroundStepPlanner.FreshNeighborCount` и `HomePressure.Build` считали непосещённые непроходимые хексы полезной территорией. Теперь оба используют `HexMap.CanEnter`. Подсчёт при отходе в `ReconReactionPolicy.PickFleeTarget` использует общий `FreshNeighborCount`, включая существующее исключение опасной территории. Видимость и авиационная разведка не изменены.
2. `WorldAnalysis.BuildThreat` вычислял подход и осаду по геометрии. Дополнительно `SightingToArmySnapshot` / `ObservationToArmySnapshot` теряли авиационный тип и ставили бюджет движения 1. Теперь наблюдаемые `IsAir` и `MaxMovement` проходят через `AiMapMemory` → `KnownEnemySighting` → `AiReconMemory` → снимок. Бюджет берётся только из видимых участников, без чтения скрытых членов армии. Изменение этих фактов обновляет `KnowledgeVersion` и сравнение наблюдений.
3. `BuildThreat` строит по одному полю стоимости `HexPathfinder.FindCosts` на контакт, а не новый маршрут для каждого объекта. Наземное поле учитывает препятствия, цену местности и максимально оплачиваемый шаг; воздушное использует `flatCost`. Скрытая занятость карты и реальные скрытые позиции врагов не используются. Поля ответа своих подвижных армий также учитывают местность; неподвижный гарнизон/аэродром не считается выездной армией ответа.
4. `ContactApproachCost` возвращает стоимость подхода от честной позиции. Для точного контакта отсутствие пути исключает пару из угроз. Для старого контакта стоимость уменьшается на максимум продвижения за прошедшие ходы; если старый маршрут отсутствует, применяется осторожная геометрическая оценка. Это не предсказание фактического скрытого маршрута. `IsSiegeThreat` использует стоимость подхода и ETA вместо расстояния по прямой. Новая стоимость включена в `WorldAnalysis.ThreatKey`, поэтому изменение близости не теряется в стратегическом сравнении при одинаковом целочисленном ETA.
5. В `ActiveDefenceObjectiveEvaluator` значение `EnemyEta` уже читалось при выборе объекта, оценке срочности и удержании последнего защитника. Теперь оно получает маршрутную оценку. `ForceNeedModel` сохраняет долгосрочный резерв для достижимой известной угрозы; задержка врага не обнуляет его силу. Недостижимые точные пары не входят в резерв. Стратегические желания и `MissionContinuityLayer` получают исправленный `UnderSiege`; ложного геометрического обходного триггера V1 в актуальном коде нет. Удалены устаревшие комментарии о таком OR.
6. `SetTerrainAt` имеет только тестовые вызовы: игровой механики изменения местности после генерации нет. Принят явный контракт **подготовки данных**, без новой системы динамического рендеринга: `HexMapGenerator.Generate` публикует фиксированную раскладку через `PublishTerrainLayout`; после этого `SetTerrainAt` возвращает `false`, не меняя ни данные, ни ревизию. Генератор по-прежнему целиком строит визуал перед `SetData`. Изменения объекта `TerrainTypeEntry` напрямую во время игры не поддерживаются. `UpdateMovePreview` дополнительно проверяет `PathingVersion`, поэтому замена данных не сохраняет прежнюю стрелку на неподвижном курсоре.
7. `WorldAnalysis.RefreshOperationalState` / `RefreshStrategicKnowledge` уже заново выполняют `Scan` при изменении `MapPathingVersion`. `SafeStepPathing` уже сбрасывает маршрутные поля по `PathingVersion`. Эти владельцы сохранены; новая таблица местности или маршрутов не добавлялась.
8. `ResolveBiome` нормализует отсутствующий/нулевой список комплексов. `PlaceComplexes` сохраняет атомарную проверку связности и теперь пишет предупреждение при некорректном шаблоне либо полном отказе размещения экземпляра после заданного числа попыток.

## Arid

В существующие верхнеуровневые `mapGeneration.terrainTypes` / `complexes` добавлены `Acid lake` и `Deep canyon`: два экземпляра двуххексового озера, семь кадров каждой части; один статичный каньон `(0,0) → (1,0) → (1,1)`.

Отдельные 512×512 текстуры находятся в `Assets/Textures/Terrain/AridSteppe/Complexes/`. Новые исходники нарисованы встроенным `imagegen` по `AridSteppe/Desert_01.png`, с исходниками Desert как ссылкой на форму/раскладку, а не как готовыми текстурами Arid. В исходных запросах: коричнево-серая охра, сухая пыльная почва, редкие приглушённые кусты и камни; строгий вид сверху; сохранить расположение озера/каньона; слабая рябь; без границ хексов, текста, UI и перспективы. Исходники сохранены в `Tools/terrain-assets/Sources/AridSteppe/`.

Вырезание частей выполняется существующим `extract.py --biome AridSteppe` из одного непрерывного источника на фазу. Каждая часть имеет собственную текстуру и материал. Общего слоя поверх комплекса нет; геометрия и альфа всех шести границ, включая внутренние, не менялись.

Разрешены только `Desert`, `Sand dunes`, `Rock desert` исходной палитры Arid. У комплексных типов `baselineWeight: 0`, `blocksGroundMovement: true`, нулевая добыча. Mountains остаются проходимыми. Desert и первые пять исходных типов Arid семантически идентичны исходной ревизии; GUID всех кадров Arid указывают в собственную папку.

Офлайн-диагностика: `aridsteppe-lake-offline-diagnostic.png`, `aridsteppe-canyon-offline-diagnostic.png`. Это **не скриншоты Unity**, они не проверяют URP, освещение, камеру, туман и игровой масштаб.

## Проверки, которые остаются для Unity

Unity Editor отсутствует. EditMode/PlayMode и реальные игровые скриншоты **не выполнены**.

Запустить полный EditMode suite, в частности новые `TerrainComplexTests`:

- `LakeDoesNotKeepHomeGapOrShoreInformationAlive`: доступная местность посещена, LocalGap = 0; при оставшейся настоящей области разведчик выбирает путь к ней;
- `CurrentGroundContactAcrossSnakeIsNotSiegeButAirIs`: близость по координатам не заменяет обход; авиация сохраняет близкую угрозу;
- `CloseGroundPassRestoresSiegeAndDefenderPin`: реальный проход возвращает реакцию и удержание защитника;
- `HistoricalContactMayAdvanceAndUnreachableOriginDoesNotRemoveRisk`: старый контакт остаётся осторожной угрозой;
- `MovementFactsSurviveReconHistoryAndChangeThreatRefreshKey`: наблюдаемые факты и ключ обновления сохраняются;
- `AuthoredComplexesKeepBothBiomesConnectedAtEverySize`: реальные настройки обоих биомов, Small–Huge, 20 seeds каждого размера (160 прогонов), только целые неперекрывающиеся комплексы, связность и нулевая добыча.

Затем выполнить PlayMode по `Docs/terrain-complexes/implementation.md`: генерация обоих биомов на Small–Huge, отсутствие контента на препятствиях, реальное движение земли и авиации. Снять Arid и Desert в игровом масштабе, проверить все семь фаз/переход 6→0 и шесть поворотов, внутренние стыки и согласованность рисунка. Отдельно проверить неподвижный курсор после полной регенерации карты.
