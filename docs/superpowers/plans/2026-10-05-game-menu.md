# Game menu implementation plan

> Execute inline with superpowers:executing-plans; independent final review.

Goal: a top-right gear button opens a non-interactive-game menu; reuse the owner-adjusted audio options and restrict Popup_Panel hiss to human turn start.

Baseline: ea5b28c (master includes the owner scene edits). Unity 6000.5.4f1, uGUI and Input System, no dependency updates.

Analysis: PopupPanelUI.ShowForHuman/ShowForOther/ShowHint share Display and VisibilityChanged. Visibility is not the required sound trigger. GameTurnController caches InputBlocked/CardDraggingBlocked via events. Camera and Escape/Space handlers bypass EventSystem. UI lives on multiple canvases, so a pointer backdrop alone cannot suppress keyboard Submit or camera movement.

Architecture: semantic HumanTurnShown event, subscribed idempotently by the existing audio binder. GameMenuPanelUI owns menu/options navigation, VisibilityChanged and a transient same-frame input guard. GameTurnController incorporates its IsShowing in existing blocked-state calculations. Gameplay canvases have CanvasGroup interaction temporarily disabled and restored; a separate overlay Canvas contains the menu. Direct input readers use UIFocusUtility.IsGameplayInputBlocked. Do not stop AI or change Time.timeScale; the requested behavior is input blocking.
